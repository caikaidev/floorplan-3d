# 户型装修设计

为这套自住房设计准备的纯前端工具：在 2D 平面图上摆放家具、测量尺寸，一键切换到 Three.js 3D 场景，校准第一人称漫游视角，并设计柜体内部收纳。无需构建或后端服务，通过静态 HTTP 服务访问。

## 功能

**2D 平面布置**
- 内置户型：三室两厅两卫（含北侧儿童房、主卧、次卧三个飘窗，入户为一梯一户电梯厅），按原始户型 1:60 / 1:100 比例显示，尺寸单位 mm
- 从左侧家具库拖入 60 余种家具家电（卧室、客厅、餐厨、卫浴、家电、书房休闲）
- 拖动移动、旋转（Shift 自由角度）、调整尺寸，贴墙自动吸附
- 测量工具（靠近墙面自动吸附，Shift 锁定水平 / 垂直）
- 拆改非承重墙，承重墙单独标示
- 图层开关：尺寸标注、房间名、家具、网格、承重墙

**3D 场景**
- 鸟瞰、斜视、俯视多种视角，点击房间列表可飞到对应房间
- 漫游模式：桌面端 WASD + 鼠标，触屏设备用虚拟摇杆，可以点门开关
- 全高墙 / 剖切墙切换，日照时间滑块，夜景灯光
- 精细家具模型：柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质等
- 在 3D 中也能选中、拖动家具，与 2D 方案实时同步

**视角和空间校准**
- 顶栏「视角校准」可设置实测眼高（含坐姿）、身体通行宽度、水平视野、全屋吊顶后净高及初始朝向
- 默认眼高 1600 mm、身体通行宽度 440 mm、水平视野 80°，进入漫游时平视；横竖屏保持相同水平视野，纵向范围随画布调整
- 2D 点「选点漫游」，再点击室内空地，可从指定位置进入；墙体、家具、飘窗占用的位置会被拒绝
- 漫游会阻挡墙体、家具、真实宽度的房门，以及展开的柜门和抽屉；地毯、墙上空调等不占地物件不阻挡
- 右下角显示眼高、水平视野及当前位置左右方向的横向净距；净距随朝向变化，并非整个通道的最窄宽度。关键位置可用 2D 测量工具复核
- 屏幕尺寸与观看距离会影响观感，应在常用设备上用同一实景站位校准；平面墙位仍为原图估算，部分位置约有 ±50 mm 误差

**柜内设计**
- 选中衣柜、到顶柜、餐边/储物柜或鞋柜，点击「编辑内部布局」打开正面剖视图
- 外尺寸默认锁定；解锁后可编辑宽、深、高。板厚、背板、门板及五金预留、踢脚高共同决定内部净尺寸
- 柜门数量与内部分区独立，调整内部不改变门面；编辑器提示抽屉跨过柜门铰链时的开启干涉，以及柜高超过净高的情况
- 点击剖视图分区，调整净宽；支持分区拆分、合并，以及长衣、短衣＋抽屉、层板、抽屉模板
- 层板底面高度和挂衣杆中心高均以柜内底板上表面为零点，单位 mm；层板支持逗号分隔输入，留空移除，挂衣杆设为 0 移除
- 可设抽屉数量与模块高度；编辑器检查组件冲突，并显示格口净高、净深、杆下可用高度及抽屉内部尺寸
- 3D 可选择关门、隐藏柜门看内部，或展开柜门与抽屉检查通道；剖视图、3D、碰撞使用同一份结构数据
- 所有编辑支持撤销和重做。复制柜子后各自独立，内部结构随本地保存和方案 JSON 一起保存
- 抽屉五金预留采用编辑器标注的估算值，柜门开启按 90°；这些用于方案比较，下单前按具体五金和现场复尺确认

**单独查看某个房间**
- 选中房间后点"单独查看这个房间"，2D 和 3D 都只显示这个房间：墙体、门窗、飘窗和房间内的家具，其他房间全部隐藏
- 2D 自动放大并标注开间 / 进深，右侧面板只显示这个房间的面积、地面材料和家具清单
- 底部（窄屏在顶部）切换栏可以直接换到别的房间，点"返回全屋"或按 `Esc` 退出

**方案与统计**
- 房间面积与套内使用面积自动统计
- 为每个房间更换地面材料（木地板、地砖、大理石、水磨石、地毯等），按面积加 5% 损耗估算造价
- 撤销 / 重做，方案自动保存在浏览器本地
- 中文 / English 界面切换（顶栏右侧按钮，默认中文，选择会记住）
- 导出 PNG 图片，导出 / 导入方案 JSON

## 快速开始

```bash
git clone <仓库地址>
cd <仓库目录>
```

在仓库目录启动本地静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

> Three.js r160 已放在 `vendor/three/` 下，应用脚本与模型模块全部从本站加载，不依赖外部 CDN。3D 需要 HTTP 访问，请不要直接双击以 `file://` 打开。

## 保存与旧方案

旧版方案会自动补齐默认视角和柜内布局。新方案格式为 version 3，浏览器使用 `huxing-design-v3` 保存；首次读取时兼容 `huxing-design-v2`，保留原来的 v2 数据。JSON 导入会先验证完整方案，非法尺寸或内部结构不会覆盖当前设计。重要方案请定期导出 JSON。

## 验证

无需安装依赖即可运行几何与数据测试（Node.js 18+）：

```bash
node --test tests/design.test.cjs
```

如环境已安装 Playwright 和 Chromium，可运行完整浏览器检查。它自动启动临时 Python 静态服务器，并在隔离的浏览器中验证旧方案、柜体编辑、复制、保存/导入、视角、碰撞与窄屏交互：

```bash
node tests/browser-smoke.cjs
# 可通过 CHROMIUM_PATH 指定 Chromium 可执行文件
```

## 部署

纯静态站点，可部署到 Cloudflare：

- **Workers（新版默认流程）**：导入本仓库，构建命令留空，部署命令保持 `npx wrangler deploy`。仓库里的 `wrangler.jsonc` 会把根目录作为静态资源发布，`.assetsignore` 排除 `.git` 等非网页文件。
- **Pages**：连接本仓库，框架预设选 None，构建命令留空，输出目录填 `/`。

绑定自己的域名可避开 `pages.dev` 在国内的访问问题。

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 2D 平面图用 SVG 绘制
- 3D 场景用 [Three.js](https://threejs.org/) r160（本地 `vendor/three/`，MIT 协议）（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 数据保存在 `localStorage`
- `design.js`：独立的柜体尺寸、视角与碰撞计算
- `cabinet-editor.js` / `cabinet-model.js`：柜内剖视编辑与 Three.js 模型
- `view-settings.js`：视角和全屋净高校准

## 自定义户型

户型数据写在 `index.html` 里：

- `ROOMS`：房间多边形、名称、默认地面材料
- `WALLS` / `WINS`：墙体与窗洞（窗的第 5 个值是窗台高度，单位 m）
- `DOORS` / `SLIDES`：平开门与推拉门
- 飘窗是 `counted:false` 的房间，台面高度 `BAY_H`，吊顶后净高 `H`
- `MATS`：地面材料名称与单价
- `LIB`：家具库（类型、名称、默认尺寸、颜色）
- `buildFurniture()`：各类家具的 3D 模型

改这些数据就能换成自己的户型。
